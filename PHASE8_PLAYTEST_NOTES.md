# Notes de playtest — Phase 8 (Équilibrage du MVP)

Objectif de cette phase : vérifier que la mécanique de sang est active, comprise et utilisée.

## Protocole

- Choisir 2, puis 3 et 4 joueurs.
- Utiliser la page avec paramètre `playtestPlayers` (2/3/4) ou, en local, `F1` puis le comptage clavier 1/2/3/4 pour rejoindre selon le nombre cible.
- Démarrer la partie avec la touche `ESPACE`.
- Surveiller les métriques de debug dans le HUD (mode debug activé par `F1` dans l’arène).
- Pour un run de validation rapide, ouvrir directement :
  - `/?playtestPlayers=2&playtest=1&matchDurationMs=10000&roundsToWin=1&maxRounds=1&countdownMs=0`
  - `/?playtestPlayers=3&playtest=1&matchDurationMs=10000&roundsToWin=1&maxRounds=1&countdownMs=0`
  - `/?playtestPlayers=4&playtest=1&matchDurationMs=10000&roundsToWin=1&maxRounds=1&countdownMs=0`
- Noter les résultats observés après chaque run.
