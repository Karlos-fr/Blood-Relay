Pas de souci. Blood Relay est probablement un meilleur choix pour toi : plus sanglant, plus spectaculaire, plus immédiatement lisible en multijoueur, et surtout plus riche visuellement sans demander une mécanique artificielle.

Je repars dessus.

Blood Relay — concept développé

Blood Relay est un jeu d’action 2D multijoueur en arènes fermées tenant sur un seul écran.

La règle centrale :

Le sang perdu par les joueurs tombe réellement dans l’arène et devient une ressource que tout le monde peut récupérer.

Tu blesses un adversaire, il saigne. Son sang éclabousse le sol, coule légèrement selon la pente et forme des flaques. N’importe quel joueur peut ensuite l’absorber pour récupérer de la vie.

Cela crée une tension simple :

* attaquer produit du soin potentiel ;
* se soigner oblige à s’exposer ;
* blesser un ennemi peut involontairement aider son allié ;
* un joueur presque mort devient une source de sang ambulante.

La boucle de jeu

Chaque manche dure environ 60 à 120 secondes.

Les joueurs apparaissent avec :

* une arme principale ;
* une attaque de mêlée ;
* une esquive courte ;
* une jauge de vie ;
* une jauge de sang absorbé.

Quand un joueur est touché :

1. il perd de la vie ;
2. une quantité équivalente de sang est projetée dans l’arène ;
3. ce sang reste disponible quelques secondes ;
4. les autres joueurs peuvent le récupérer en passant dessus.

Le sang ne soigne pas instantanément. Il remplit une réserve temporaire.

Le joueur doit ensuite maintenir une touche pendant une demi-seconde pour se transfuser. Cela évite qu’un simple passage sur une flaque annule immédiatement les dégâts.

Les trois états du joueur

Stable

Le joueur ne saigne plus et peut se battre normalement.

Hémorragie

Sous un certain seuil de vie, le joueur laisse régulièrement tomber de petites gouttes.

Cette trace permet de le suivre et le force à continuer à bouger.

Exsangue

À zéro point de vie, le joueur ne meurt pas immédiatement.

Il tombe au sol et peut :

* ramper ;
* donner un coup faible ;
* tirer une dernière balle s’il en possède une ;
* être relevé par un allié ;
* être achevé par un adversaire.

Cela produit des retournements intéressants sans ajouter un système compliqué.

Le vrai cœur tactique : le vol de sang

Chaque joueur possède une réserve de sang distincte de sa vie.

Quand il traverse une flaque, il l’absorbe automatiquement jusqu’à atteindre sa capacité maximale.

Mais le sang garde pendant quelques secondes la couleur de son propriétaire.

Exemple :

* le sang rouge provient du joueur rouge ;
* le joueur bleu le récupère ;
* s’il est éliminé avant de se transfuser, il libère à nouveau ce sang.

La ressource peut donc circuler plusieurs fois entre les joueurs. C’est le véritable “relais” du titre.

Les armes

Je limiterais le premier jeu à six armes très distinctes.

Revolver lourd

* tir précis ;
* dégâts élevés ;
* projection de sang concentrée ;
* cadence lente.

Très lisible et idéal pour commencer.

Fusil à pompe

* énorme projection ;
* faible portée ;
* pousse fortement la cible ;
* produit beaucoup de petites flaques.

Pistolet-mitrailleur

* faibles dégâts par balle ;
* oblige à suivre la cible ;
* crée une piste de sang progressive.

Arbalète

* le carreau traverse le joueur ;
* peut le clouer temporairement au mur ;
* le sang reste concentré autour du point d’impact.

Machette

* attaque courte ;
* aucun projectile ;
* coupe brutalement une grande quantité de vie ;
* excellent pour défendre une flaque.

Lance-grenades

* explosion lente et télégraphiée ;
* projette joueurs et sang dans toutes les directions ;
* dangereux pour tout le monde.

Je ne mettrais pas d’armes aléatoires au départ. Chaque joueur choisit son arme avant la manche afin que la lecture reste claire.

Les actions communes

Chaque personnage dispose des mêmes actions :

* courir ;
* sauter ;
* descendre d’une plateforme ;
* esquiver ;
* frapper ;
* tirer ;
* absorber du sang ;
* se transfuser ;
* relever un allié.

Il faut éviter les doubles sauts, grappins, parades complexes et capacités héroïques. La profondeur doit venir du sang et du positionnement.

Le système de transfusion

Le joueur peut se soigner à tout moment avec le sang stocké, mais :

* il ralentit fortement ;
* il ne peut pas tirer ;
* une petite lueur le rend visible ;
* l’action est interrompue s’il reçoit un coup.

Cela crée des moments où un joueur doit choisir entre fuir et prendre le risque de se soigner.

Une transfusion complète ne devrait jamais rendre toute la vie. Je viserais environ 60 à 70 % de récupération maximale pour éviter les combats interminables.

Les arènes

Chaque niveau tient entièrement dans l’écran, sans caméra.

Une bonne arène contient :

* deux ou trois hauteurs ;
* quelques plateformes traversables ;
* une zone centrale exposée ;
* deux routes de contournement ;
* un élément interactif ;
* aucun cul-de-sac long.

Exemples

Abattoir
Crochets suspendus, tapis roulant, broyeur central.

Bloc opératoire
Tables mobiles, portes automatiques, lumière blanche agressive.

Métro abandonné
Un train traverse périodiquement le bas de l’écran et disperse les flaques.

Chapelle rouge
Sol incliné vers un autel central où le sang s’accumule.

Usine de transfusion
Pompes et conduites capables d’aspirer puis de rejeter le sang ailleurs.

Le niveau doit modifier la circulation du sang sans voler la vedette aux joueurs.

Les modes de jeu

Carnage

Chacun pour soi. Le premier à atteindre un nombre d’éliminations gagne.

C’est le mode parfait pour le prototype.

Relais

Deux équipes partagent chacune une réserve de vie globale.

Le sang récupéré par un joueur peut être transféré à un allié.

C’est le mode qui donne tout son sens au titre.

Dernier vivant

Pas de réapparition pendant la manche. Les joueurs exsangues peuvent être relevés.

Banque de sang

Une cuve apparaît au centre. Les équipes doivent y déposer du sang récupéré.

Déposer oblige à rester immobile quelques secondes.

Hémorragie

Tout le monde perd lentement de la vie. Le seul moyen de survivre est de prendre du sang aux autres.

Très violent, mais à garder comme mode secondaire.

La direction visuelle

Je viserais un rendu :

* sprites rétro 16 ou 32 bits ;
* animations courtes et exagérées ;
* décor sombre ;
* silhouettes très lisibles ;
* sang beaucoup plus fluide et détaillé que le reste.

Le contraste entre les personnages pixel art et les effets modernes ferait toute l’identité.

Effets modernes

* éclairage dynamique ;
* ombres douces ;
* particules physiques ;
* sang qui colle aux murs ;
* traces de pas ;
* reflets sur les flaques ;
* léger ralenti lors d’un coup décisif ;
* vibration et recul de caméra ;
* flashes d’impact ;
* distorsion lors des explosions.

Le sang doit être spectaculaire mais rester lisible. S’il couvre tout l’écran après trente secondes, la mécanique devient illisible. Il faut donc qu’il sèche progressivement ou soit absorbé par le décor.

Le ton

Je déconseille un univers trop réaliste ou morbide. Cela compliquerait la diffusion et rendrait le jeu désagréable.

Je verrais plutôt :

* mercenaires futuristes ;
* clones condamnés ;
* prison télévisée ;
* laboratoire clandestin ;
* sport illégal ultra-violent.

Le sang peut être rouge, violet, vert ou noir selon les personnages. Cela aide la lisibilité et donne un ton plus arcade.

Le meilleur cadre narratif

Des clones combattent dans une émission clandestine. Leur sang est une substance recyclable utilisée pour les maintenir en vie.

Cela justifie :

* les réapparitions ;
* les couleurs de sang différentes ;
* les transfusions rapides ;
* les arènes artificielles ;
* le nom Blood Relay.

Pas besoin de narration lourde. Une intro de vingt secondes suffit.

Le MVP à réaliser avec Codex

Pour vérifier si le jeu est amusant, il faut couper très fort.

Contenu

* une arène ;
* deux personnages ;
* deux armes : revolver et fusil à pompe ;
* deux à quatre joueurs locaux ;
* un seul mode : carnage ;
* vie, saignement et flaques ;
* absorption et transfusion ;
* réapparition ;
* clavier et manettes.

Ce qu’il ne faut pas faire au début

* jeu en ligne ;
* campagne ;
* bots sophistiqués ;
* dix armes ;
* éditeur de niveaux ;
* cosmétiques ;
* démembrement complexe ;
* liquide entièrement simulé ;
* progression ;
* comptes utilisateurs.

Pour le sang, une vraie simulation de fluide serait une erreur. Il vaut mieux utiliser :

* particules à l’impact ;
* decals au sol ;
* flaques circulaires qui fusionnent visuellement ;
* légère animation de propagation ;
* quantités enregistrées numériquement.

Tu obtiendras 90 % de l’effet pour une fraction de la complexité.

Stack que je choisirais

Pour un prototype rapide :

* TypeScript ;
* Vite ;
* Phaser 3 ou PixiJS avec une petite couche physique ;
* Matter.js uniquement si les corps et projections le nécessitent ;
* WebGL pour les lumières et shaders ;
* Gamepad API ;
* Web Audio API.

Phaser est probablement le choix le plus efficace pour sortir rapidement un jeu jouable. Ton moteur maison viendrait plus tard seulement si le concept fonctionne.

Le test décisif

Le prototype est validé si cette situation apparaît naturellement :

Un joueur blesse sévèrement son adversaire, rate l’achèvement, puis les deux se précipitent vers la même flaque parce qu’elle peut sauver l’un ou condamner l’autre.

Si cette course autour du sang est amusante, tu tiens le jeu. Si les joueurs ignorent les flaques et continuent simplement à tirer, le concept ne fonctionne pas encore.

Le nom Blood Relay fonctionne très bien. Il décrit la circulation de la ressource et possède une sonorité suffisamment arcade.
